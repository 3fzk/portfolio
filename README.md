# LUYN NETWORK — Horror Portfolio

A static, mobile-first horror portfolio made for **luynnetwork.app** and Instagram bio traffic.

## Before publishing
1. Replace `YOUR NAME` in `index.html`.
2. Replace the `#` project/social links.
3. Put your royalty-free ambient audio at `assets/ambient.mp3`.
4. Change the email if needed.

## Netlify
- Create a new site in Netlify.
- Drag the project folder (or upload the ZIP after extracting it) into Netlify.
- No build command is required.
- Publish directory: `/` (the project root).

## Custom domain
In Netlify, open your site's **Domain management → Add custom domain** and add:
`luynnetwork.app`

Then follow the DNS records Netlify gives you at your domain registrar. DNS values can vary, so use Netlify's current instructions rather than hard-coding records here.

## Audio note
Browsers commonly block autoplay with sound. This site intentionally starts silent and has a **SOUND OFF / SOUND ON** control so visitors choose when to hear the ambience.
