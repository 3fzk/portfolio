# Almas / Luyn Network Portfolio

A dependency-free, responsive portfolio site. Open `index.html` in a browser to preview it.

## Deploy

Upload these files to any static host (Netlify, Vercel, Cloudflare Pages, or GitHub Pages). No build command is needed; the publish directory is the project root.

External links are already set to:

- Main website: `https://luynnetwork.app`
- Panel: `https://panel.luynnetwork.app`
- Instagram: `https://instagram.com/alms.0x`
